# 每日待办 - Web 版

一个本地运行的现代 Todo 工作台，基于 React + Vite + TypeScript 重构。

## 功能

- 每日待办：按日期管理任务，支持前一天、后一天和回到今天。
- 日常总控台：打开应用先看到今日概览、习惯打卡和今日重点任务。
- 本周待办：按当前日期所在自然周维护本周事项。
- 每月待办：在左侧栏进入独立视图，支持按年月查看和维护月任务。
- 每周快递：在左侧栏进入独立视图，记录本周快递并维护未取/已取状态。
- 灵感记录：在左侧栏进入独立视图，记录每日灵感，支持搜索、置顶、编辑和归档。
- 视频灵感：在左侧栏进入独立视图，整理高价值视频，支持渠道筛选、搜索、置顶、编辑和归档。
- 元学习力：在左侧栏进入独立视图，沉淀学习能力卡片，支持搜索、掌握程度筛选、编辑和归档。
- 习惯打卡：维护每日固定习惯，按真实今天打卡并显示连续天数。
- 真棒记录：按日期记录当天值得纪念或有价值的事情。
- 默认任务：首次打开当天会自动补充默认任务。
- 任务状态：未完成、进行中、已完成。
- 标签分类：全部、未分类、生活、学习、工作。
- 优先级：高、中、低。
- 搜索筛选：支持按任务标题和描述搜索。
- 进度统计：展示当天完成数量和完成百分比。
- 任务操作：添加、编辑、删除、拖拽排序、清除已完成。
- 继承昨日：把昨天未完成任务复制到今天，并保留标签、描述和优先级。
- 历史回顾：查看已有日期的完成情况，并可跳转到对应日期。
- 主题切换：浅色和深色主题。

## 技术栈

- React
- TypeScript
- Vite
- lucide-react
- Node 本地 API
- 项目目录 JSON 文件持久化

## 运行

首次运行先安装依赖：

```bash
npm install
```

启动开发服务器：

```bash
npm run dev
```

这个命令会同时启动：

- 前端页面：http://127.0.0.1:5173/
- 本地数据 API：http://127.0.0.1:5174/

构建生产版本：

```bash
npm run build
```

运行测试：

```bash
npm run test
```

## 目录

```text
src/
├── components/        # 页面区域、任务卡片、弹窗和基础控件
├── hooks/             # 撤销/重做等状态逻辑
├── services/          # 项目文件 API、localStorage 兜底和数据归一化
├── App.tsx            # 主应用状态与业务编排
├── constants.ts       # 状态、标签、默认任务等常量
├── date.ts            # 日期格式化和日期计算
├── main.tsx           # React 入口
├── styles.css         # 全局 UI 样式
└── types.ts           # Todo 类型定义
```

```text
server/
├── index.mjs          # 本地 JSON 数据 API
├── schema.mjs         # 后端写入校验
└── dev.mjs            # 同时启动前端和后端
```

```text
todo-data/
├── todos.json    # 待办数据
└── prefs.json    # 主题等偏好
```

## 数据存储

应用会优先通过本地 API 把数据保存到项目目录下的 `todo-data/`。

如果本地 API 没启动，前端会临时退回到浏览器 `localStorage`，避免页面不可用。正式使用时建议始终通过 `npm run dev` 启动。

原 Python/tkinter 版本文件已统一移动到 `legacy/`，作为历史实现参考。
