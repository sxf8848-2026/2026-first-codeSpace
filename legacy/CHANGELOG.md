## [5.1.0] - 2026-08-16

### 新增
- **每日默认任务**：配置文件 `data/default_tasks.json` 定义每天默认任务
  - 每天第一次启动时自动添加默认任务到当天列表
  - 切换到某一天时也会自动应用默认任务
  - 同一天多次启动不会重复添加
  - 已有相同内容的任务会自动跳过
  - 默认任务可配置标题、标签、优先级

### 配置文件格式
```json
{
  "tasks": [
    {"text": "起床", "tag": 1, "priority": "medium"},
    {"text": "洗脸", "tag": 1, "priority": "medium"}
  ]
}
```
- `tag`: 0=未分类, 1=生活, 2=学习, 3=工作
- `priority`: high / medium / low

## [5.0.0] - 2026-08-16

### 新增
- **任务标签系统**：支持四种标签分类
  - 0-未分类（默认）、1-生活、2-学习、3-工作
  - 添加任务时可通过标签按钮选择标签
  - 任务卡片上显示彩色标签（生活=绿、学习=蓝、工作=橙）
- **标签筛选**：
  - 当天任务列表支持按标签筛选（全部/未分类/生活/学习/工作）
  - 历史回顾窗口支持按标签筛选查看完成情况
- 数据结构版本升级到 v5，新增 `tag` 字段
- 自动数据迁移：v4 数据自动补充 `tag: 0`（未分类）

### 变更
- 添加区域新增标签选择按钮（与状态选择按钮并列）
- 工具栏新增标签筛选分段控件
- 历史回顾窗口顶部新增标签筛选器

### 数据迁移
- 旧数据（v1-v4）启动时自动迁移到 v5，无需手动操作
- 迁移前自动备份原数据到 `data/backups/` 目录

## [3.0.0] - 2026-08-16

### 新增
- **任务状态系统**：任务状态从布尔值（完成/未完成）扩展为三态
  - `0` - 已完成
  - `1` - 未完成
  - `2` - 进行中
- 添加任务时可选择状态（输入框旁状态选择按钮，弹出菜单选择）
- 筛选器支持四态：全部 / 未完成 / 进行中 / 已完成
- 进行中任务显示橙色「进行中」标签，文字用橙色高亮
- 主题新增 `warning` / `warning_soft` 配色（进行中状态使用）

### 变更
- 数据结构版本升级到 v3，`done` 字段替换为 `status`
- 自动数据迁移：v2 的 `done: true/false` 自动转为 `status: 0/1`
- `toggle()` 逻辑调整：未完成/进行中 → 已完成，已完成 → 未完成
- 历史回顾窗口适配新的 status 字段
- 撤销/重做操作保留任务状态

### 数据迁移
- 旧数据（v1/v2）启动时自动迁移到 v3，无需手动操作
- 迁移后原 `done` 字段保留（兼容），新代码统一使用 `status`

## [2.0.0] - 2026-08-16

### 新增
- **MVC 架构重构**：将原来 700+ 行的 `app.py` 拆分为控制器、视图、状态管理三层
  - `state.py`：轻量状态管理（观察者模式）
  - `views/`：视图层目录，包含主视图、任务行、弹窗、历史窗口
  - `app.py`：精简为控制器，只负责业务逻辑和协调
- **搜索功能**：工具栏搜索框，实时过滤任务（不区分大小写）
- **优先级系统**：高/中/低三级优先级，左侧彩色指示条 + 标签，支持按优先级筛选
- **撤销/重做**：Ctrl+Z 撤销，Ctrl+Y / Shift+Ctrl+Z 重做
  - 支持操作：添加、删除、切换完成、编辑、清除已完成
  - 输入框内的 Ctrl+Z 不触发全局撤销
- **两列网格布局**：任务列表从一行一个改为一行两个，空间利用率更高
- 工程化文件：`requirements.txt`、`.gitignore`、单元测试

### 变更
- `storage.py` 数据版本升级到 v2，新增 `priority` 字段
- 自动数据迁移：v1 数据自动补充 `priority: "medium"`
- `widgets.py` 优化：
  - `RoundedButton` 新增 disabled 状态
  - `Tooltip` 新增屏幕边界检测，超出时自动调整位置
  - `ScrollFrame` 滚轮事件全局只绑定一次，解决多滚动区域冲突
- `TaskRow.update_task()` 改为只重建子控件，不破坏外部 grid/pack 布局
- 所有 storage 修改方法返回数据副本，避免外部直接修改内部数据

### 修复
- 多个 ScrollFrame 共存时滚轮事件冲突的问题
- Tooltip 在屏幕边缘显示不全的问题
